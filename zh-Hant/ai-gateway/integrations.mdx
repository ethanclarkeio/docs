選擇您使用的工具，依照教學設定 DGrid AI Gateway，並驗證第一筆模型請求。

## 開始之前

準備好 [DGrid 帳號](https://dgrid.ai/)、可用餘額，以及可存取目標模型的 [Model API Key](https://dgrid.ai/api-keys)。請使用完整模型 ID，包含供應商前綴；每篇教學會列出該工具所需的連線參數、環境與限制。

<Info>
Model API Key 用於呼叫模型。Management API Key 僅用於管理操作，無法用於這些教學的模型請求。
</Info>
