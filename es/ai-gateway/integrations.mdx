Elija su herramienta, configure DGrid AI Gateway y verifique su primera solicitud al modelo.

## Antes de empezar

Prepare una [cuenta de DGrid](https://dgrid.ai/), saldo disponible y una [Model API Key](https://dgrid.ai/api-keys) con acceso al modelo elegido. Use el ID completo del modelo, incluido el prefijo del proveedor. Cada guía indica los parámetros de conexión, los requisitos del entorno y las limitaciones de la herramienta.

<Info>
Use una Model API Key para las solicitudes a los modelos. Las Management API Keys son credenciales administrativas y no sirven para estos tutoriales.
</Info>
