Auto Deposit을 사용하면 자금 지갑에서 누적 USDT 지출 한도를 승인할 수 있습니다. 충전 잔액이 설정한 기준보다 낮아지면 DGrid가 목표 잔액까지 필요한 금액을 계산하고, 사용 가능한 승인 한도 내에서 지갑에 청구합니다. 거래가 확인되면 충전 잔액에 반영됩니다. 지갑의 USDT가 부족하면 사용 가능한 금액만 충전합니다.

[DGrid Billing](https://dgrid.ai/billing) → <strong>Deposit</strong> → <strong>Auto Deposit</strong>으로 이동하세요.

## 시작하기 전에

- DGrid에 로그인하고 Auto Deposit에 사용할 지갑을 연결하세요.
- 페이지에 표시된 네트워크와 토큰을 확인하세요. 현재 설정 창에는 <strong>BNB Chain</strong>과 <strong>USDT</strong>가 표시됩니다. 자금 지갑에는 USDT와 최초 USDT 승인 거래의 가스비를 지불할 소량의 BNB가 필요합니다.
- <strong>충전 잔액(Deposit Balance)</strong>은 구독 잔액을 제외하며 자동 충전의 실행 조건과 충전 금액 계산에 사용됩니다. <strong>자금 지갑(Funding wallet)</strong>은 온체인 USDT를 보유합니다. 승인 한도를 설정해도 전체 금액이 즉시 DGrid로 이동하지 않습니다.

<Note>
승인하기 전에 Billing 페이지와 지갑 요청에 표시된 네트워크, 토큰, 승인 수신 주소를 확인하세요.
</Note>

<strong>자동 충전 계약 주소(BNB Chain):</strong> [0xF1846bf5562b4E45e054B02E99244fd7a44Db66F](https://bscscan.com/address/0xF1846bf5562b4E45e054B02E99244fd7a44Db66F#code). 링크를 열어 주소와 온체인에 공개된 계약 코드가 있는지 확인하세요.

## 자동 충전 규칙 설정

[Billing](https://dgrid.ai/billing)의 <strong>Deposit</strong>에서 <strong>Auto Deposit</strong>을 선택하고 <strong>Set Up Auto Deposit</strong>을 클릭하세요.

| 필드 | 설명 |
| --- | --- |
| <strong>Network / Token</strong> | 읽기 전용이며 현재 BNB Chain / USDT입니다. |
| <strong>Funding wallet</strong> | 충전 비용을 지불할 지갑입니다. 연결된 지갑과 일치하는지 확인하세요. |
| <strong>Trigger balance</strong> | 충전 잔액이 이 값보다 낮아지면 실행됩니다. 0 이상으로 설정할 수 있습니다. |
| <strong>Target balance</strong> | 충전 후 도달할 충전 잔액입니다. 실행 기준보다 높아야 합니다. |
| <strong>Approved limit</strong> | 이 승인으로 청구할 수 있는 누적 USDT 한도입니다. 최소한 “목표 잔액 − 실행 기준 잔액” 이상이어야 합니다. 실행 전에 잔액이 더 감소할 수 있으므로 여유를 두세요. 매번 청구되는 금액이 아닙니다. |
| <strong>Maximum auto-deposit amount</strong> | 페이지가 계산하는 읽기 전용 상한입니다. 현재 규칙에서는 목표 잔액과 같습니다. |
| <strong>Expiry date</strong> | 미래의 승인 만료일입니다. 만료 후에는 다시 승인해야 합니다. |

예상 청구액과 가스비 안내를 확인하고 <strong>Enable Auto Deposit</strong>을 클릭하세요.

예를 들어 실행 기준을 10 USDT, 목표를 200 USDT, 누적 승인 한도를 1,000 USDT로 설정합니다. 실행 시 충전 잔액이 8 USDT라면 192 USDT(200 − 8)가 필요합니다. 지갑과 승인 한도가 충분하면 192 USDT를 청구하며, 사용한 승인 금액은 192 USDT, 남은 한도는 808 USDT입니다. 지갑에 50 USDT만 있다면 50 USDT를 청구하여 충전 잔액은 58 USDT, 남은 승인 한도는 950 USDT가 됩니다. 실제 금액은 실행 시점의 잔액을 기준으로 계산됩니다.

## 지갑 승인 완료

페이지와 지갑 요청에 따라 순서대로 진행하세요.

<Steps>

<Step title="USDT allowance 승인">

네트워크, USDT 토큰, spender 주소, 승인 금액을 확인하고 온체인 거래를 확정하세요. 이 거래의 BNB 가스비는 사용자가 지불합니다.

</Step>

<Step title="Auto Deposit 승인 서명">

지갑에서 서명을 요청하면 내용을 검토하고 서명하세요. 서명해도 전체 승인 금액이 즉시 청구되지 않습니다.

</Step>

<Step title="등록 대기">

상태가 <strong>Active</strong>가 되고 자금 지갑, 승인 금액, 만료일이 표시되어야 설정이 완료됩니다. 지갑의 Approve만 성공했다고 활성화된 것은 아닙니다.

</Step>

</Steps>

승인 등록과 이후 자동 충전 거래의 가스비는 DGrid가 지불합니다. 거래 거절, 서명 실패, 등록 실패 시 페이지의 오류 안내에 따라 처리하고 최종 상태가 <strong>Active</strong>인지 확인하세요.

## 청구 금액 계산 이해

상태가 <strong>Active</strong>이면 DGrid가 규칙과 실행 시점의 충전 잔액을 기준으로 목표까지 필요한 금액을 계산합니다.

```text
Amount needed to reach target = Target balance − Deposit Balance at execution
Actual deposit = min(Amount needed to reach target, available wallet USDT)
```

이 공식은 남은 승인 한도가 충분하고 토큰 allowance가 유효하다고 가정합니다. 지갑의 USDT가 부족하면 부분 충전하므로 목표 잔액에 도달하지 못할 수 있습니다. 사용 가능한 USDT가 없으면 청구할 수 없습니다. 승인 한도나 allowance가 부족하면 페이지 안내에 따라 다시 승인하세요. 온체인 확인과 계정 반영이 필요하므로 실행 조건을 충족한 직후 잔액이 갱신되지 않을 수 있습니다.

<strong>Approved limit / Total authorization은 누적 한도</strong>입니다. 성공한 충전마다 한도를 사용합니다. 진행 중인 금액은 <strong>Processing</strong>에 표시되고, 성공하면 <strong>Used</strong>로 이동하며 실패하면 해제됩니다. <strong>Remaining</strong>은 남은 한도입니다. 새 승인은 이전 승인을 대체하며 기존 잔여 한도에 더해지지 않습니다.

## 승인 확인 및 관리

- <strong>Auto Deposit</strong> 페이지에서 상태, <strong>Total authorization</strong>, <strong>Used</strong>, <strong>Processing</strong>, <strong>Remaining</strong>, <strong>Authorization expiry</strong>를 확인하세요.
- <strong>Manage</strong>를 클릭하세요. <strong>Pause</strong>는 일시 중지, <strong>Resume</strong>은 재개합니다. <strong>Edit / Adjust Credit</strong>으로 설정이나 한도를 변경하고 요청 시 지갑 승인을 다시 완료하세요.
- 남은 한도가 부족하거나 allowance가 유효하지 않거나 승인이 만료되면 <strong>Re-Authorize</strong>를 선택하세요.
- <strong>Revoke</strong>는 Auto Deposit 승인을 취소합니다. <strong>Set Allowance to 0</strong>은 지갑의 USDT 지출 allowance를 별도로 제거하며, 가스비가 드는 추가 온체인 거래가 필요할 수 있습니다. allowance가 부족하면 자동 충전이 일시 중지됩니다. 다시 사용하려면 <strong>Re-Authorize</strong>를 선택하세요. 변경하려는 항목에 맞는 작업을 선택하세요.
- <strong>Payment History</strong>에서 <strong>Type: Auto</strong>인 기록의 금액, 시간, <strong>Tx Hash</strong>를 확인하세요. 승인만으로 충전 기록이 생성되지는 않습니다.
