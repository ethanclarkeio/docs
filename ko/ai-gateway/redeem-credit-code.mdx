DGrid Credit Code를 받으셨다면 다음 단계에 따라 credits를 DGrid 계정에 추가하세요.

<Steps>

<Step title="지갑을 연결하고 로그인하기">

[DGrid](https://dgrid.ai/)로 이동하여 지갑을 연결하고 계정에 로그인하세요.

<Frame caption="지갑을 연결하여 DGrid에 로그인하기">
  <img src="/images/dgrid-credit-login.png" alt="지갑을 연결하여 DGrid에 로그인" />
</Frame>

</Step>

<Step title="Billing 열기">

오른쪽 상단의 프로필 아바타를 클릭한 다음 <strong>Billing</strong>을 선택하세요.

<Frame caption="프로필 메뉴에서 Billing 열기">
  <img src="/images/dgrid-credit-billing.png" alt="DGrid 프로필 메뉴에서 Billing 열기" />
</Frame>

</Step>

<Step title="Credit Code 검증하기">

<strong>Billing</strong> 페이지에서 <strong>Deposit</strong> 섹션까지 아래로 스크롤한 후 <strong>Redeem Code</strong>를 클릭하세요. code를 입력한 다음 <strong>Validate Code</strong>를 클릭하세요.

<Frame caption="DGrid Credit Code 입력 및 검증하기">
  <img src="/images/dgrid-credit-redeem-code.png" alt="Deposit 섹션에서 DGrid Credit Code 입력 및 검증" />
</Frame>

</Step>

<Step title="교환 확인하기">

code 세부 정보를 확인한 후 <strong>Confirm Redeem</strong>을 클릭하세요. credits가 계정에 즉시 적용됩니다.

<Frame caption="DGrid Credit Code 교환 확인하기">
  <img src="/images/dgrid-credit-confirm.png" alt="DGrid Credit Code 교환 세부 정보 확인" />
</Frame>

</Step>

</Steps>

이제 DGrid를 사용할 수 있습니다. 문제가 발생하면 [DGrid Telegram 커뮤니티](https://t.me/dgrid_ai)로 문의해 주세요.
