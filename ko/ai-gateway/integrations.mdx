도구를 선택하고 DGrid AI Gateway를 설정한 다음 첫 모델 요청을 확인하세요.

## 시작하기 전에

사용 가능한 잔액과 선택한 모델에 대한 접근 권한이 있는 [DGrid 계정](https://dgrid.ai/) 및 [Model API Key](https://dgrid.ai/api-keys)를 준비하세요. 공급자 접두사가 포함된 전체 모델 ID를 사용하세요. 각 가이드에서 연결 설정, 환경 요구 사항 및 제한 사항을 안내합니다.

<Info>
모델 요청에는 Model API Key를 사용하세요. Management API Key는 관리용 자격 증명이므로 이 가이드의 모델 요청에 사용할 수 없습니다.
</Info>
