Choose your tool, configure DGrid AI Gateway, and verify your first model request.

## Before you start

Have a [DGrid account](https://dgrid.ai/), available credits, and a [Model API Key](https://dgrid.ai/api-keys) with access to your chosen model. Use the complete model ID, including its provider prefix. Each guide lists the connection settings, environment requirements, and limitations for that tool.

<Info>
Use a Model API Key for model requests. Management API Keys are administrative credentials and cannot be used for these tutorials.
</Info>
