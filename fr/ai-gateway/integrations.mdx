Choisissez votre outil, configurez DGrid AI Gateway et vérifiez votre première requête au modèle.

## Avant de commencer

Préparez un [compte DGrid](https://dgrid.ai/), des crédits disponibles et une [Model API Key](https://dgrid.ai/api-keys) autorisée à utiliser le modèle choisi. Utilisez l'ID complet du modèle, préfixe du fournisseur inclus. Chaque guide précise les paramètres de connexion, les prérequis et les limites de l'outil.

<Info>
Utilisez une Model API Key pour les requêtes aux modèles. Les Management API Keys servent à l'administration et ne conviennent pas à ces tutoriels.
</Info>
