---

Suivez ces étapes pour utiliser un code de crédit et ajouter des crédits à votre compte DGrid.

<Steps>

<Step title="Connectez votre wallet">

Accédez à [DGrid](https://dgrid.ai/) et connectez votre wallet.

<Frame>
  <img src="/images/dgrid-credit-login.png" alt="Connexion du wallet sur DGrid" />
</Frame>

</Step>

<Step title="Ouvrez la page Billing">

Ouvrez le menu de votre profil en haut à droite, puis sélectionnez **Billing**.

<Frame>
  <img src="/images/dgrid-credit-billing.png" alt="Option Billing dans le menu du profil DGrid" />
</Frame>

</Step>

<Step title="Validez votre code">

Sur la page **Billing**, faites défiler jusqu'à la section **Deposit**. Cliquez sur **Redeem Code**, saisissez votre code, puis cliquez sur **Validate Code**.

<Frame>
  <img src="/images/dgrid-credit-redeem-code.png" alt="Saisie et validation d'un code de crédit DGrid" />
</Frame>

</Step>

<Step title="Confirmez l'utilisation du code">

Vérifiez les détails, puis cliquez sur **Confirm Redeem**. Les crédits sont immédiatement ajoutés à votre compte.

<Frame>
  <img src="/images/dgrid-credit-confirm.png" alt="Confirmation de l'utilisation d'un code de crédit DGrid" />
</Frame>

</Step>

</Steps>

## Commencez à explorer DGrid

Vos crédits sont prêts à être utilisés. Commencez à explorer DGrid et, si vous avez besoin d'aide, rejoignez la [communauté DGrid sur Telegram](https://t.me/dgrid_ai).
